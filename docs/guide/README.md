# lumina guide

How to use lumina for what you want to do with it. Each page is a short walk through; the [README](../../README.md) lists everything the app does, and **Options** inside the app has every shortcut.

| I want to… | Page |
|---|---|
| Open a video and capture the lighting states | [Capturing](capturing.md) |
| Print a cue sheet, download the images, save my work | [Cue sheet and sessions](cue-sheet.md) |

The video never leaves your machine: it is read by the browser, and nothing is uploaded. `test/test-2997.mp4` in the repository is a 20-second test video with the frame numbers burned in, if you want to try the app without a recording of your own.
